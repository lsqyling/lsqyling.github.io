1. 基础概念

1.1 窗口状态

GlazeWM 中的窗口有三种状态：

状态 说明
Tiling（平铺） 窗口自动排列，互不重叠，充分利用屏幕空间
Floating（浮动） 窗口可自由移动和调整大小，悬浮在其他窗口之上
Fullscreen（全屏） 窗口占据整个屏幕

默认状态：floating（浮动），新窗口默认以浮动模式创建。

1.2 平铺方向

平铺方向决定了新窗口的插入位置：

  • 水平（默认）：新窗口在右侧平铺
  • 垂直：新窗口在下方平铺

2. 窗口管理

2.1 焦点切换

使用以下快捷键在窗口之间移动焦点：

快捷键 操作
Alt + H / Alt + ← 焦点向左移动
Alt + L / Alt + → 焦点向右移动
Alt + K / Alt + ↑ 焦点向上移动
Alt + J / Alt + ↓ 焦点向下移动

2.2 移动窗口

将当前焦点窗口移动到指定方向：

快捷键 操作
Alt + Shift + H / Alt + Shift + ← 窗口向左移动
Alt + Shift + L / Alt + Shift + → 窗口向右移动
Alt + Shift + K / Alt + Shift + ↑ 窗口向上移动
Alt + Shift + J / Alt + Shift + ↓ 窗口向下移动

2.3 调整窗口大小

快捷键 操作
Alt + U 宽度减少 2%
Alt + P 宽度增加 2%
Alt + O 高度增加 2%
Alt + I 高度减少 2%

调整模式（入模式后使用 HJKL 或方向键）：

快捷键 操作
Alt + R 进入/退出调整大小模式

调整模式下可用按键：

按键 操作
H / ← 宽度减少 2%
L / → 宽度增加 2%
K / ↑ 高度增加 2%
J / ↓ 高度减少 2%
Esc / Enter 退出调整模式

2.4 窗口状态切换

快捷键 操作
Alt + V 切换平铺方向（水平/垂直）
Alt + Space 循环切换焦点：平铺 → 浮动 → 全屏
Alt + Shift + Space 切换当前窗口为浮动（居中）
Alt + T 切换当前窗口为平铺
Alt + F 切换当前窗口为全屏
Alt + M 最小化当前窗口
Alt + Shift + Q 关闭当前窗口

2.5 窗口规则

配置中包含以下自动忽略规则：

匹配条件 说明
zebar 进程 忽略 Zebar 窗口（任务栏/状态栏）
Picture-in-Picture 标题 + Chrome/Mozilla 类 忽略浏览器画中画窗口
PowerToys 进程 + 特定类 忽略 PowerToys 相关窗口
Lively 进程 忽略 Lively 动态壁纸窗口
EXCEL 进程（非 XLMAIN 类） 忽略 Excel 非主窗口
WINWORD 进程（非 OpusApp 类） 忽略 Word 非主窗口
POWERPNT 进程（非 PPTFrameClass 类） 忽略 PowerPoint 非主窗口

3. 窗口效果

3.1 焦点窗口

效果 值 说明
边框 启用，颜色 #ff0000（红色） 高亮当前焦点窗口
标题栏 禁用（可启用） 移除窗口标题栏
圆角 禁用 可设为方角/圆角/小圆角（仅 Win11）
透明度 禁用 可设置窗口透明度

3.2 非焦点窗口

效果 值 说明
边框 启用，颜色 #a1a1a1（灰色） 显示窗口边界
标题栏 禁用 移除窗口标题栏
圆角 禁用 可设为方角/圆角/小圆角（仅 Win11）
透明度 启用，不透明度 80% 非焦点窗口半透明显示

4. 工作区管理

4.1 工作区定义

配置了 9 个工作区，名称分别为 1 到 9。

4.2 切换工作区

快捷键 操作
Alt + 1 ~ Alt + 9 切换到对应编号的工作区
Alt + S 切换到下一个活跃工作区
Alt + A 切换到上一个活跃工作区
Alt + D 切换到最近使用的工作区

4.3 移动窗口到工作区

快捷键 操作
Alt + Shift + 1 ~ Alt + Shift + 9 移动窗口到对应工作区并切换过去

4.4 跨显示器移动工作区

快捷键 操作
Alt + Shift + A 将当前工作区移到左侧显示器
Alt + Shift + F 将当前工作区移到右侧显示器
Alt + Shift + D 将当前工作区移到上方显示器
Alt + Shift + S 将当前工作区移到下方显示器

5. 全局设置

5.1 边距

参数 值
窗口间间距 1px
屏幕顶部外边距 1px
屏幕右侧外边距 1px
屏幕底部外边距 1px
屏幕左侧外边距 1px
随 DPI 缩放 是

5.2 光标行为

参数 值
光标跟随焦点 禁用
光标跳跃 启用，切换显示器时跳转
工作区重复聚焦切换 启用

5.3 窗口隐藏方式

cloak（推荐 Windows 模式），窗口切换工作区时自动隐藏。

5.4 任务栏显示

只显示当前工作区的窗口（show_all_in_taskbar: false）。

窗口状态
