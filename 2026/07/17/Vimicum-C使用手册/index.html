Vimium C 使用手册

Posted on 2026-07-17 Edited on 2026-07-26

前言: Vimium C 是一款全键盘操作浏览器的扩展程序，支持 Chrome/Edge 等 Chromium 内核浏览器。

核心概念

Vimium C 提供两种操作模式：

  • 命令模式（正常模式）：默认模式，可直接使用快捷键浏览网页
  • 插入模式：按 i 进入，临时暂停快捷键，按 Esc 退出
  • 可视化模式：按 <f8> 或 v 进入，使用键盘选择文字
  • 页内查找模式：按 / 进入，搜索页面内容

多功能搜索框（Vomnibar）

Vimium C 的地址栏 / 搜索框，按快捷键后输入关键词搜索或跳转。

按键 说明
o 多功能搜索框（搜索历史 + 收藏夹 + 搜索引擎）
O 搜索内容并在新标签页打开
b 搜索收藏夹
B 搜索收藏夹并在新标签页打开
T 在所有标签页中搜索
ge 编辑当前网址
gE 编辑当前网址并在新标签页打开

复制 / 剪贴板

按键 说明
yy 复制当前标签页网址或标题
p 在当前标签页打开复制的网址
P 在新标签页打开复制的网址
yf 复制链接的网址
yi 复制图片到剪贴板

按键 说明
m 在当前页面位置创建一个标记
` 跳转到指定标记

自定义与配置

Vimium C 支持通过扩展程序选项页面自定义快捷键和参数。

常用参数说明

部分快捷键支持参数配置，格式为：

参数 说明
button="" / right 链接点击使用鼠标左键 / 右键
hard 强制刷新（跳过缓存）
keepHover=true / false 滚动时是否保持鼠标悬停位置
trailingSlash=true / false 访问上级网址时是否保留尾部斜杠
wrap=true / false 切换到首 / 尾标签页后是否循环
decoded 复制时使用解码后的 URL
reuse=current / newFg / newBg 指定打开链接的方式
