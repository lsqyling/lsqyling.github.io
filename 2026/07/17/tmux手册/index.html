Tmux 手册

Posted on 2026-07-17 Edited on 2026-07-26

前言: Tmux—终端复用器，用于在一个终端窗口中管理多个会话、窗口和面板。

核心概念：黏滞模式

按下 C-b 进入黏滞命令模式，连续输入命令，Enter 或 Esc 退出。

传统 tmux 需要每次 C-b + 命令，本配置已改为类似 vim 的模态操作：按一次 C-b 进入模式，之后可连续按下多个命令（如 j j k k），最后 Enter 退出。

备用传统前缀：F12（使用标准 tmux 前缀模式）

状态提示

进入黏滞模式后，状态栏左侧会显示白字红底的 [STICKY] 提示，退出后自动消失。

进入与退出

按键 说明
C-b 进入黏滞模式（同时显示 [STICKY] 提示）
Enter 确认并退出黏滞模式
Esc 取消并退出黏滞模式

面板导航

按键 说明
h 切换到左边面板
j 切换到下边面板
k 切换到上边面板
l 切换到右边面板
o 按顺序切换到下一个面板
q 显示面板编号（按编号跳转）
; 切换到上一个面板

面板大小调整

按键 说明
H 向左扩大 5 列
J 向下扩大 5 行
K 向上扩大 5 行
L 向右扩大 5 列

面板分割

按键 说明
% 垂直分割（左右）
| 垂直分割（左右，同 %）
" 水平分割（上下）
- 水平分割（上下，同 "）

面板操作

按键 说明
x 🔴 关闭当前面板（需按 y 确认）
X 🔴 关闭当前窗口（需按 y 确认）
z 全屏 / 还原当前面板
! 将面板拆分为独立窗口
{ 与上一个面板交换位置
} 与下一个面板交换位置
Space 循环切换面板布局

窗口管理

按键 说明
c 🟡 新建窗口（需按 y 确认，防误触）
n 下一个窗口
p 上一个窗口
w 交互式选择窗口
0 - 9 切换到指定编号的窗口
, 重命名当前窗口
. 移动当前窗口（按编号）
g 按编号跳转到窗口

会话管理

按键 说明
s 交互式选择会话
d 🔴 分离当前会话（提示 detach the session? (yes/n)，必须输入完整 yes）
D 🔴 杀死当前会话（提示 kill the session? (yes/n)，必须输入完整 yes）
$ 重命名当前会话
( 上一个会话
) 下一个会话

滚动与搜索（Copy Mode）

进入黏滞模式（C-b），再按 [ 进入 Copy Mode。

进入与退出

按键 说明
[ 进入 Copy Mode
q 或 Esc 退出 Copy Mode

滚动

按键 说明
j 向下滚一行
k 向上滚一行
Ctrl+u 向上翻半页
Ctrl+d 向下翻半页
Ctrl+b 向上翻一页
Ctrl+f 向下翻一页
g 滚到顶部
G 滚到底部

搜索

按键 说明
/ 向前搜索
? 向后搜索
n 下一个匹配
N 上一个匹配

选择与复制

按键 说明
v 开始选择文本
y 复制选中文本到 tmux 缓冲区
Ctrl+c 复制选中文本到 Windows 剪贴板（WSL）

复制 / 粘贴

按键 说明
[ 进入 Copy Mode
] 粘贴 tmux 缓冲区内容
= 交互式选择缓冲区
# 列出所有缓冲区

其他

按键 说明
: 打开 tmux 命令提示符
? 列出当前所有按键绑定
r 刷新终端显示
t 显示时钟
m 显示消息历史
i 显示当前窗口信息

防御策略说明

为防止黏滞模式中误触破坏性操作，以下按键配置了确认机制：

级别 方式 按键 说明
🟡 标准确认 按 y 确认，n 取消 c x X 新建窗口、关闭面板/窗口
🔴 严格确认 必须输入完整 yes 才执行 d D 分离会话、断开客户端

典型案例

  • 黏滞模式中想导航到 Claude 面板：C-b → j → j → l，安全
  • 若误触 d 再按 y：不会触发 detach（必须完整输入 yes）
  • 若误触 x：弹窗提示，按 n 可取消

会话管理（Shell 命令）

命令 说明
tmux new -s <name> 创建名为 name 的会话
tmux ls 列出所有会话
tmux attach -t <name> 重新连接到指定会话
tmux kill-session -t <name> 删除指定会话
tmux kill-server 删除所有会话（退出 tmux）
