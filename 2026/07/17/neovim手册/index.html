NeoVim 使用手册

Posted on 2026-07-17 Edited on 2026-07-27

前言: Neovim 是基于 Vim 的一个现代化分支（fork），它的定位是“hyperextensible Vim-based text editor”——一个基于 Vim、具备超强扩展能力的文本编辑器。 简单来说，Neovim 不是对 Vim 的重写，而是延续和扩展。它保留了 Vim 的核心操作哲学——高效、快速、键盘驱动、极简，同时通过架构层面的革新，让这个经典的编辑器能够更好地适应现代开发需求。

Telescope — 模糊搜索

Telescope 是你在 Vibe Coding 中最高频使用的工具，用于快速定位文件和代码。

快捷键

按键 功能 说明
<leader>ff Find Files 按文件名搜索（基于 fd）
<leader>fw Live Grep 按文件内容搜索（基于 ripgrep）
<leader>fb Buffers 在已打开的 buffer 间切换
gr LSP References 查看光标下符号的所有引用位置

常用操作

按下快捷键后，底部会出现 Telescope 输入框：

操作 按键
上下选择结果 <C-n> / <C-p> 或方向键
打开选中文件 <CR>
预览文件内容 自动显示在右侧预览窗
在新的垂直分屏打开 <C-v>
在新的水平分屏打开 <C-x>
在新 tab 打开 <C-t>
关闭 Telescope <Esc> 或 <C-c>

技巧：Live Grep 支持正则搜索，输入 class.*Window 可以搜索包含该模式的代码行。

Oil — 文件浏览器

Oil 用纯 vim buffer 的方式展示目录，你在里面操作文件就像编辑文本一样自然。不使用侧边栏式的文件树（nvim-tree）。

打开

按键 功能
- 打开 Oil，浏览当前文件所在目录

界面

这就是一个普通的 vim buffer，所有操作都和编辑文本一致。

基本操作

按键 功能
j / k 上下移动
<CR> 打开文件 / 进入目录
- 返回上级目录
q 关闭 Oil
dd 删除文件/目录
yy 复制文件/目录
p 粘贴文件/目录
r 重命名文件/目录
~ 跳转到 home 目录
g? 显示 Oil 帮助（所有按键绑定）

设计理念：Oil 会把你的文件编辑操作（dd/yy/p/r）直接映射为文件系统操作。比如 dd 一个文件不会删除文本，而是会删除这个文件（确认后）。比 nvim-tree 更快更轻量。

nvim-cmp — 自动补全

进入插入模式后，输入代码时会自动弹出补全建议框。

补全来源

来源 说明
nvim_lsp clangd 提供的语义补全（类型准确）
luasnip 代码片段展开
buffer 当前 buffer 中已有的单词
path 文件路径补全（#include 时很有用）

操作

操作 按键
选择下一项 <C-n> 或 <Tab>
选择上一项 <C-p> 或 <S-Tab>
确认选择 <C-y>
关闭补全框 <C-e>
滚动文档 <C-f> / <C-d>
展开/跳转 snippet <Tab>（在补全框关闭时）
